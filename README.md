## About me

I’m **He3HaukaX**, the developer behind **hPlugin**. I build Minecraft plugins, server mechanics, administration tools and integrations. My work also includes websites, applications and a private server fork based on Leaf.

I started building plugins because existing solutions often lacked the flexibility and functionality I needed. That is still what drives my work: **more control over server behavior, broader functionality and a strong focus on optimization**.

<a name="approach"></a>

## Engineering approach

**Optimization.** I focus on reducing unnecessary server load without sacrificing functionality.

**Flexibility.** Configurable mechanics, settings and integrations — not just editable messages.

**Functionality.** Solutions built around the server’s tasks rather than the limits of a template.

## Experience on live servers

I previously worked with a Minecraft server running **around 500 concurrent players**. I now also work with projects in the **100–200 concurrent-player range**, including servers using my published resources.
